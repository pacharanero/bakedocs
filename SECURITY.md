# Security Policy

## Reporting A Problem

Report suspected vulnerabilities or sensitive findings through a [private GitHub security advisory](https://github.com/pacharanero/bakedocs/security/advisories/new). Do not put exploit details, credentials, internal paths, or confidential documents in a public issue or discussion.

Include the affected command or file, the impact, safe reproduction steps, and any suggested mitigation. Do not test against third-party systems, brand owners, or production services without explicit written authorisation.

## Scope

The maintained Bash scripts, templates, styles, and brand-profile handling are in scope. External tools and CDN resources should be reported to their upstream maintainers as well as noted privately here when they affect `bakedocs`.

The repository must not contain credentials, personal data, member exports, or confidential source documents. Treat any accidental disclosure as sensitive and rotate exposed credentials immediately.
